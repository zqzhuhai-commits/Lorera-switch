# 运行期第三方组件许可提示

以下组件由 devkitPro 构建环境提供，随 NRO/NSP 二进制分发（按各自许可证要求保留声明）：

| 组件 | 许可 | 版权方 |
|---|---|---|
| libnx | zlib | switchbrew 项目 |
| devkitA64 | GPLv3+（运行库例外） | devkitPro 项目 |
| SDL2 | zlib | Sam Lantinga |
| Mesa / libGLESv2 / EGL | MIT | Mesa 项目 |
| libdrm-nouveau | MIT | 自由桌面项目 |
| FreeType | FTL / GPLv2 | FreeType 项目 |
| HarfBuzz | MIT | HarfBuzz 项目 |
| libpng | libpng/zlib | PNG 参考库作者 |
| FFmpeg（含 dav1d、opus、tremor、webp、ogg） | LGPL/GPL（动态链接） | FFmpeg 团队等 |
| switch-bzip2 | BSD | Julian Seward |

完整许可证文本见各组件官方发布。图标取自 Steam 商店页官方宣传图（Lorera © 96Brothers）。
